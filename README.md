# Task 2 – EDA 

## Overview

Performed basic Exploratory Data Analysis (EDA) on an e-commerce sales dataset using Python.

## Tools

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

* Dataset overview
* Missing values & duplicate check
* Numerical & categorical analysis
* Product-wise sales analysis
* Payment method analysis
* Order status analysis
* Coupon & referral analysis
* Year-wise & month-wise sales trends
* Basic visualizations

## Dataset

* 1,200 orders
* 14 columns
* No missing values
* No duplicate records

##  Key Insights

* Chair generated the highest product revenue.
* Credit Card generated the highest payment revenue.
* Instagram was the top referral source.
* FREESHIP generated the highest coupon revenue.
