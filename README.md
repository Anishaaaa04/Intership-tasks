Task 3 : SQL

Task  Overview:
This project focuses on analyzing an orders dataset using SQL queries. The objective is to extract useful insights from the data using basic SQL concepts such as SELECT, WHERE, ORDER BY, GROUP BY, COUNT, SUM, and AVG.

Dataset:
The dataset contains order-related information such as:

* Order ID
* Order Date
* Customer ID
* Product
* Quantity
* Unit Price
* Shipping Address
* Payment Method
* Order Status
* Tracking Number
* Items in Cart
* Coupon Code
* Referral Source
* Total Price

SQL Analysis Performed:

1. Retrieved data using SELECT queries.
2. Filtered records using WHERE.
3. Sorted records using ORDER BY.
4. Grouped data using GROUP BY.
5. Counted total orders using COUNT().
6. Calculated total revenue using SUM().
7. Calculated average order value using AVG().
8. Analyzed orders by payment method.
9. Analyzed revenue generated by each product.
10. Filtered high-value orders based on Total Price.
11. Analyzed orders based on Order Status.
12. Calculated average quantity by product.

Key Insights:

* Identified the total number of orders.
* Calculated the overall revenue generated.
* Found the average order value.
* Compared order counts across different payment methods.
* Identified products based on their revenue contribution.
* Analyzed high-value orders and order status distribution.

Tools Used:

* Oracle SQL
* Oracle Live SQL
* Excel Dataset

Skills Demonstrated:
SQL Fundamentals, Data Filtering, Data Sorting, Data Aggregation, Data Grouping, Basic Data Analysis
